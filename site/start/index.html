Get started

Get started with Fazit

Run the demo on your own computer in a few minutes. It needs no Microsoft account and sends nothing anywhere.

Run in a terminal

git clone https://github.com/rouxdutoit/fazit && cd fazit && uv run fazit demo

Needs Git and uv. What you need

What you need

  • Git

    Downloads Fazit's source code. Get Git

  • uv

    Sets up the right Python and every package on the first run. Install uv

Fazit runs on Windows, macOS and Linux.

Run the demo

This builds the sample report for a fictional town administration, in English. For German, run uv run fazit demo --lang de in the same folder.

Open the report

The last line of the output shows where the report was saved. Open that HTML file in your browser.

To check that Fazit works without a network, disconnect, run uv run --offline fazit demo and open the report again.

How to verify offline operation
