Roadmap

Project status

You can run Fazit from source and build reports from the bundled samples with your own answers and costs.

  1. Now

    The measured figures in the samples are simulated. Fazit is not yet on PyPI.

  2. Next

    Import CSV exports from the Microsoft 365 admin centre on your computer, keeping only aggregates, and show where your tenant’s data is stored.

  3. Later

    Install with one command, or run a signed Windows program without Python. Each release lists its checksums and contents.

    The report will cover Microsoft 365 Copilot and Copilot Studio and show the deadline for a renewal decision. CSV export for project plans, a report integrity check and links to the sovereignty criteria of ZenDiS, the federal centre behind openDesk, are planned.

    Sign in read-only to check permissions and count licences and directory entries.

French and Italian are planned with the Swiss pilot. The translation guide shows how to add a language.
