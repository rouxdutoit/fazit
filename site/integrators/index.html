For integrators

If you advise on openDesk, Nextcloud or similar setups, you can use Fazit in your own assessments. The tool is free to use and licensed under AGPL-3.0-or-later.

Use Fazit in an assessment

Run Fazit on the client’s computer. Use the report to discuss what the organisation relies on, which functions need a separate plan and which costs matter for each scenario. The report is vendor-neutral and names no service provider.

Today you can run the bundled example or build a report from an existing scan file. Local import of admin-centre exports is the next feature.
