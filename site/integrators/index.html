Plan the next steps from the findings

Use the findings to identify which exports and answers to request from your client. The report groups open points by the evidence needed and names the responsible role for each. That lets you request each item once even if it affects several areas.

CSV export for project plans is planned for phase 1.2.

Use Fazit in an assessment

When local import is available, you will be able to run Fazit at the client’s site and use the report to discuss dependencies, work to plan separately and costs for each scenario.

Today you can try the bundled example and add your own answers and costs. The measured figures in the samples are simulated. Local import of admin-centre exports comes next; the roadmap shows what follows.

Firms can request a directory entry

After the first assessments, firms that have run at least one real assessment with Fazit can request a free entry in the alphabetical directory by emailing their name, public website and consent to hello@rouxdutoit.com.

Do not send us client names, scan files or reports. They stay with the client.
