Hindernisse erkennen, bevor das Projekt sie findet

Viele Behörden und Unternehmen erwägen, Microsoft 365 abzulösen: wegen der digitalen Souveränität, des Datenschutzes oder der Kosten. Nur wenige können genau sagen, wovon sie abhängen.

Hindernisse wie die Telefonie oder Hunderte geschäftskritischer Makros zeigen sich dann erst mitten im Projekt. Fazit soll diese Frage vorher beantworten, mit den Daten Ihrer eigenen Organisation. Zu jedem Befund zeigt es die Nachweise. Wo sie fehlen, steht „Unbekannt“.

Fazit vergibt keine Gesamtnote und empfiehlt keinen Anbieter. Ob, was und wann umgestellt wird, entscheidet Ihre Organisation.

Datenschutz von Grund auf

Ihre Daten bleiben auf Ihrem Rechner. Fazit erstellt den Bericht lokal, und die aktuelle Version baut überhaupt keine Netzwerkverbindung auf.

  • Läuft auf Ihrem Rechner

    Der Bericht ist eine einzelne Datei auf Ihrem eigenen Laufwerk. Nichts wird hochgeladen, es gibt kein Konto und keinen Clouddienst.

  • Keine Netzwerkverbindungen

    Die aktuelle Version kontaktiert keinen Server. Später soll sich Fazit nur bei Microsoft anmelden und über Microsoft Graph ausschließlich lesen.

  • Nur Lesezugriff

    Fazit schreibt nie in Microsoft 365 und speichert keine Anmeldetokens, Personennamen oder E-Mail-Adressen.

  • Offen nachprüfbar

    Für jede Schutzmaßnahme gibt es einen Test, den jeder ausführen kann. Auch ohne Netzwerkverbindung läuft das Beispiel.

Was Fazit nie tut

  • In Microsoft 365 schreiben oder Endpunkte außerhalb der Freigabeliste aufrufen.
  • Daten von Ihrem Rechner übertragen. Die aktuelle Version baut keine Netzwerkverbindung auf. Die geplante Anmeldung mit reinem Lesezugriff spricht nur mit der Microsoft-Anmeldung und Microsoft Graph.
  • Anmeldetokens, Personennamen oder E-Mail-Adressen speichern. Der Bericht kann nur den Namen Ihrer Organisation und die Namen reiner Windows-Anwendungen enthalten, die Sie selbst eintragen.
  • Externe Ressourcen in den Bericht nachladen.
  • Ergebnisse erfinden oder eine Einstufung verbessern, weil eine Prüfung ausgelassen wurde.

Selbst nachprüfen

Trennen Sie nach dem ersten Lauf die Netzwerkverbindung. Führen Sie uv run --offline fazit demo --lang de aus und öffnen Sie den Bericht im Browser.

So funktioniert Fazit

Beispiel aus dem Quellcode starten

git clone https://github.com/rouxdutoit/fazit && cd fazit && uv run fazit demo --lang de

  1. Vorbereiten

    Installieren Sie Git und uv. Beim ersten Start werden die benötigten Python-Pakete geladen. Das Beispiel läuft ohne Microsoft-Konto.

  2. Beispiel ausführen

    Der Befehl oben erzeugt den Beispielbericht auf Deutsch. Für die englische Fassung führen Sie im Projektverzeichnis uv run fazit demo aus.

  3. Bericht öffnen

    Öffnen Sie die HTML-Datei, deren Pfad Fazit am Ende ausgibt. Der Bericht dokumentiert die Nachweise für jeden Befund und zeigt, was noch zu prüfen ist.

Was die Befunde aussagen

Der Bericht nennt zu jedem Befund, soweit vorhanden, Quelle, Datum, Berichtszeitraum und Umfang der Erhebung. Er kennzeichnet Zahlen als erhoben, bereitgestellt oder unbekannt. Bei fehlenden Nachweisen nennt er den Grund und den nächsten Prüfschritt. Fehlen erforderliche Kostenangaben, bleibt die Summe unbekannt.

Fazit bewertet jeden Bereich einzeln. Eine Gesamtbewertung gibt es nicht. Über den Umstieg entscheidet Ihre Organisation.

Fazit prüft die Angaben auf Widersprüche. Erfundene, aber in sich schlüssige Angaben erkennt es nicht. Der Bericht ist nur so verlässlich wie die Personen und Programme, die die Nachweise geliefert haben.

Projektstand

Verfügbar
Sie können Fazit aus dem Quellcode starten und Berichte aus Beispieldaten oder einer vorhandenen Erhebungsdatei erstellen. Das Paket ist noch nicht auf PyPI veröffentlicht.
Als Nächstes
KI-Assistenten wie Microsoft 365 Copilot und Copilot Studio werden zu einem eigenen Prüfbereich. Der Bericht zeigt, wann Ihre Lizenzen verlängert werden und bis wann Sie entscheiden müssen.
Danach
Ein Export der Befunde für Projektpläne, eine Prüfung, ob ein Bericht nachträglich verändert wurde, und zu jedem Befund ein Verweis auf die Souveränitätskriterien des ZenDiS, des Bundeszentrums hinter openDesk.
Anschließend
Fazit soll CSV-Exporte aus dem Microsoft 365 Admin Center auf Ihrem Rechner einlesen, nur Anzahlen speichern und zeigen, wo die Daten Ihres Mandanten liegen.
Später
Nach einer Anmeldung mit reinem Lesezugriff soll Fazit Berechtigungen prüfen und Lizenzen und Verzeichniseinträge zählen.
Sprachen
Französisch und Italienisch sind mit dem Schweizer Pilotprojekt geplant. Fazit ist auf Übersetzungen ausgelegt; die Anleitung beschreibt das Vorgehen.

Wie Fazit entsteht

Claude und Codex helfen beim Schreiben und Prüfen des Codes. Ein Mensch leitet die Arbeit und verantwortet das Ergebnis. Für jede Schutzmaßnahme der aktuellen Version gibt es einen Test, den Sie selbst ausführen können. Die Anmeldung erscheint mit eigenen Tests.

Wir arbeiten nach den Grundsätzen des No-AI-Slop-Manifests: Ein Mensch verantwortet jede Änderung, KI-geschriebene Arbeit ist gekennzeichnet, und für jede Schutzmaßnahme gibt es einen Test.
