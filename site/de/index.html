Für Entscheidungen zur digitalen Souveränität in Deutschland, Österreich und der Schweiz

Ihre Abhängigkeit von Microsoft 365, belegt

Fazit zeigt, worauf Ihre Organisation angewiesen ist, was bei einem Umstieg auf openDesk, Nextcloud oder LibreOffice zu klären ist und was er über fünf Jahre kosten würde. Das kostenlose Open-Source-Programm erstellt den Bericht auf Ihrem Rechner.

Warum Fazit

Viele Behörden und Unternehmen erwägen einen Umstieg von Microsoft 365 – aus Gründen der digitalen Souveränität, des Datenschutzes oder der Kosten. Nur wenige können genau sagen, wovon sie abhängen.

Das Hindernis, mit dem niemand gerechnet hat, etwa die Telefonie oder Hunderte geschäftskritische Makros, zeigt sich dann erst mitten im Projekt. Fazit ist darauf ausgelegt, diese Frage vorab zu beantworten, auf Grundlage der Daten Ihrer Organisation. Es legt für jeden Befund die Nachweise offen und nennt „unbekannt“, wo Nachweise fehlen.

Fazit vergibt keine Gesamtnote und empfiehlt keinen Anbieter. Ob, was und wann umgestellt wird, entscheidet Ihre Organisation.

Datenschutz von Grund auf

Ihre Daten bleiben auf Ihrem Rechner. Fazit erstellt den Bericht lokal, und die aktuelle Version baut überhaupt keine Netzwerkverbindung auf.

  • Läuft auf Ihrem Rechner

    Der Bericht ist eine einzelne Datei auf Ihrem eigenen Laufwerk. Nichts wird hochgeladen, es gibt kein Konto und keinen Clouddienst.

  • Keine Netzwerkverbindungen

    Die aktuelle Version kontaktiert keinen Server. Die spätere Direkterhebung spricht nur mit der Microsoft-Anmeldung und Microsoft Graph, und nur lesend.

  • Nur Lesezugriff

    Fazit schreibt nie in Microsoft 365 und speichert keine Anmeldetokens, Personennamen oder E-Mail-Adressen.

  • Offen nachprüfbar

    Für jede Schutzmaßnahme gibt es einen Test, den jeder ausführen kann. Auch ohne Netzwerkverbindung läuft das Beispiel.

Was Fazit ausschließt

  • Schreibzugriffe auf Microsoft 365 sowie Aufrufe außerhalb der Freigabeliste für Lesezugriffe.
  • Eine Übertragung von Prüfdaten. Die aktuelle Version baut keine Netzwerkverbindung auf. Anmeldung und Direkterhebung bleiben später auf die Microsoft-Anmeldung und Microsoft Graph beschränkt.
  • Die Speicherung von Anmeldetokens oder erhobenen Personennamen und E-Mail-Adressen. Der Bericht kann den von Ihnen eingetragenen Namen Ihrer Organisation und die Namen reiner Windows-Anwendungen enthalten.
  • Das Nachladen externer Ressourcen aus dem Bericht.
  • Erfundene Ergebnisse oder eine bessere Einstufung durch ausgelassene Prüfungen.

Selbst nachprüfen

Trennen Sie nach dem ersten Lauf die Netzwerkverbindung. Führen Sie uv run --offline fazit demo --lang de aus und öffnen Sie den Bericht im Browser.

Zuordnungen und Quellen ansehen

Für wen Fazit gedacht ist

IT-Dienstleister
Führen Sie für jeden Kunden dieselbe belegte Bestandsaufnahme durch und leiten Sie den Projektplan aus den Befunden ab. Unternehmen, die eine echte Bestandsaufnahme mit Fazit durchgeführt haben, können sich kostenlos eintragen lassen.
Kommunale IT-Dienstleister
Bieten Sie Ihren Mitgliedsorganisationen eine Bestandsaufnahme an, bei der die Daten auf dem ausführenden Rechner bleiben.
IT-Leitungen
Führen Sie Fazit selbst aus und legen Sie Ihrer Leitung einen belegten Bericht vor. Für das Beispiel brauchen Sie kein Microsoft-Konto.

So funktioniert Fazit

Beispiel aus dem Quellcode starten

git clone https://github.com/rouxdutoit/fazit && cd fazit && uv run fazit demo

  1. Vorbereiten

    Installieren Sie Git und uv. Beim ersten Start werden die benötigten Python-Pakete geladen. Das Beispiel läuft ohne Microsoft-Konto.

  2. Beispiel ausführen

    Der Befehl oben erzeugt das Beispiel auf Englisch. Für den deutschen Bericht führen Sie im Projektverzeichnis uv run fazit demo --lang de aus.

  3. Bericht öffnen

    Öffnen Sie die HTML-Datei, deren Pfad Fazit am Ende ausgibt. Der Bericht dokumentiert die Nachweise für jeden Befund und zeigt, was noch zu prüfen ist.

Was die Befunde aussagen

Der Bericht nennt zu jedem Befund, soweit vorhanden, Quelle, Datum, Berichtszeitraum und Umfang der Erhebung. Er kennzeichnet Zahlen als erhoben, bereitgestellt oder unbekannt. Bei fehlenden Nachweisen nennt er den Grund und den nächsten Prüfschritt. Fehlen erforderliche Kostenangaben, bleibt die Summe unbekannt.

Fazit bewertet jeden Bereich einzeln. Eine Gesamtbewertung gibt es nicht. Über den Umstieg entscheidet Ihre Organisation.

Auch in sich schlüssige, erfundene Angaben können die Prüfung bestehen, weshalb die Aussagekraft des Berichts von den Personen und Programmen abhängt, die die Nachweise erstellt haben.

Projektstand

Verfügbar
Sie können Fazit aus dem Quellcode starten und Berichte aus Beispieldaten oder einer vorhandenen Erhebungsdatei erstellen. Das Paket ist noch nicht auf PyPI veröffentlicht.
Als Nächstes
Fazit soll CSV-Exporte aus dem Microsoft 365 Admin Center lokal einlesen und die zusammengefassten Daten behalten.
Später
Berechtigungen prüfen und nach einer Anmeldung mit reinem Lesezugriff Anzahlen zu Lizenzen und Verzeichniseinträgen erheben.

Wie Fazit entsteht

Claude und Codex unterstützen die Entwicklung und prüfen gegenseitig ihren Code. Der Projektverantwortliche leitet die Arbeit und verantwortet das Ergebnis. Für jede Schutzmaßnahme der aktuellen Version gibt es einen Test, den Sie selbst ausführen können. Die Tests für die Direkterhebung folgen mit der Anmeldung.
