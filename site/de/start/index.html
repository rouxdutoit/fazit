Mit Fazit starten

Führen Sie das Beispiel in wenigen Minuten auf Ihrem eigenen Rechner aus. Sie brauchen kein Microsoft-Konto, und es werden keine Daten übertragen.

Im Terminal ausführen

git clone https://github.com/rouxdutoit/fazit && cd fazit && uv run fazit demo --lang de

Sie brauchen Git und uv. Was Sie brauchen

Was Sie brauchen

  • Git

    Lädt den Quellcode von Fazit herunter. Git herunterladen

  • uv

    Richtet beim ersten Start die passende Python-Version und alle Pakete ein. uv installieren

Fazit läuft unter Windows, macOS und Linux.

Das Beispiel ausführen

Der Befehl erzeugt den Beispielbericht für eine fiktive Stadtverwaltung auf Deutsch. Für die englische Fassung führen Sie im selben Ordner uv run fazit demo aus.

Den Bericht öffnen

Die letzte Zeile der Ausgabe nennt den Pfad des Berichts. Öffnen Sie die HTML-Datei in Ihrem Browser.

Um zu prüfen, dass Fazit ohne Netzwerk arbeitet, trennen Sie die Verbindung, führen uv run --offline fazit demo --lang de aus und öffnen den Bericht erneut.

Anleitung zur Prüfung ohne Netzwerk

Mit eigenen Daten

Heute erstellt Fazit Berichte aus den Beispieldaten oder aus einer Erhebungsdatei, ergänzt um Ihre eigenen Antworten und Kosten in inputs.yaml. Als Nächstes kann Fazit Exporte aus dem Microsoft 365 Admin Center einlesen. Bis dahin sind die Pilotprüfungen der Weg, Ihre eigene Organisation zu bewerten.
