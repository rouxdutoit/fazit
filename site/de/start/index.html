Mit Fazit starten

Führen Sie das Beispiel auf Ihrem eigenen Rechner aus. Sie brauchen kein Microsoft-Konto, und nach der Einrichtung läuft es ohne Netzwerkverbindung.

Im Terminal ausführen

git clone https://github.com/rouxdutoit/fazitcd fazituv run fazit demo --lang de

Sie brauchen Git und uv. Was Sie brauchen

Was Sie brauchen

  • Git herunterladen

    Lädt den Quellcode von Fazit herunter.

  • uv installieren

    Richtet beim ersten Start die passende Python-Version und alle Pakete ein.

Fazit wird unter Windows, macOS und Linux getestet.

Das Beispiel ausführen

Der Befehl erzeugt den Beispielbericht für eine fiktive Stadtverwaltung auf Deutsch. Für die englische Fassung führen Sie im selben Ordner uv run fazit demo aus.

Den Bericht öffnen

Die letzte Zeile der Ausgabe nennt den Pfad des Berichts. Öffnen Sie die HTML-Datei in Ihrem Browser.

Um zu prüfen, dass Fazit ohne Netzwerk arbeitet, trennen Sie die Verbindung, führen uv run --offline fazit demo --lang de aus und öffnen den Bericht erneut.

Anleitung zur Prüfung ohne Netzwerk

Mit eigenen Daten

Derzeit erstellt Fazit Berichte aus den Beispieldaten, ergänzt um Ihre eigenen Antworten und Kosten in inputs.yaml. Die Bestandszahlen stammen dabei weiter aus der fiktiven Stadtverwaltung. Als Nächstes kommt der Import von Exporten aus dem Microsoft 365 Admin Center; bis dahin können Sie Interesse an einer Pilotprüfung bekunden.
