Security and privacy

The current version of Fazit runs on your computer and contains no network code. A read-only sign-in to Microsoft is planned.

Report a vulnerability

Principles

  • Read-only

    The planned sign-in will request read permissions and use a list of approved read endpoints. Any request that could change the tenant is excluded, even one that uses GET.

  • Local processing

    Fazit keeps assessment data on the computer, as long as the scan, inputs and --out directory are on local storage: a network share sends those files over the network. Usage exports will be imported offline. The planned sign-in will contact only login.microsoftonline.com and graph.microsoft.com, with no telemetry, analytics, update checks or content delivery networks.

  • Tokens in memory

    When sign-in is added, access and refresh tokens will stay in memory and never be written to disk.

  • Metadata only

    Planned collection will be limited to counts, sizes and coded evidence. Fazit leaves mail bodies and file contents unopened.

  • Personal data

    The scan format excludes collected person names and email addresses, and Fazit discards unrecognised fields. The report can show the organisation name and Windows-only application names you enter in inputs.yaml.

  • Offline report

    The report is one HTML file with inline CSS and embedded Figtree and Geist Mono fonts. It opens and prints without a network connection, JavaScript or external resources.

  • One command

    After setup, one command builds a report from bundled samples or a compatible scan with your own answers and costs. Measured figures come from the samples. Planned sign-in will use the browser with PKCE and offer a device code as a fallback.

  • Honest figures

    The report calculates only with costs you supply and marks example figures as examples. Missing evidence stays unknown, and a skipped or denied check never improves readiness.

Verify offline operation

  1. Set up Git and uv, clone the repository and run uv run fazit demo once to install the dependencies.
  2. Disconnect the computer from the network. In the same directory, run uv run --offline fazit demo.
  3. Open the HTML file named on the last line of the output, then open the print preview. Both work while disconnected.

See the installed package’s offline test

Limits of the evidence

Fazit checks the scan and inputs for contradictions and labels the source of each figure. An internally consistent fabrication can still produce a report. The report depends on the people and tools that produced its evidence.

The appendix records the scan’s stated origin, producer and version.

Print a PDF without file paths

Your browser may add the local file path when you print. Turn off Headers and footers in the print settings, then check the preview for the file path before you save or share the PDF.

Report a vulnerability

Use GitHub’s private vulnerability form. If the form is unavailable, email hello@rouxdutoit.com.

Do not disclose the vulnerability publicly. Use fictional examples, not real scans or reports.
