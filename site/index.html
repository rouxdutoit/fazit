Find the blockers before the project does

Many public bodies and companies are weighing a move away from Microsoft 365, for digital sovereignty, data protection or cost. Before deciding, they need to know what they depend on.

Telephony is a typical example: an assigned Teams Phone licence that no project plan mentions. Fazit shows the evidence for each finding and marks missing evidence as “Unknown”. Today it works with sample data; import of your own exports comes next.

It gives no overall score and recommends no supplier.

What stays on your computer

Fazit builds the report on your computer. Once installed, it makes no network requests, and the report loads nothing from anywhere. Keep inputs and reports in a local folder that is not synchronised, and they stay on this machine.

  • Runs on your computer

    The report is one file in a folder you choose. Fazit uploads nothing and needs no account or cloud service.

  • No network requests

    Today Fazit contacts no server. The planned read-only sign-in will talk only to Microsoft sign-in and Microsoft Graph.

  • Read-only by design

    The planned sign-in will ask only for read permissions and keep tokens in memory. The scan holds counts and codes, not personal names or email addresses.

  • Open to inspection

    Tests anyone can run show that Fazit stays offline and that reports load nothing external. The sign-in safeguards get their tests with the code.

What Fazit will never do

  • Write to a Microsoft tenant or call an endpoint outside the read allowlist.
  • Send assessment data off your computer. The planned sign-in will talk only to Microsoft sign-in and Microsoft Graph.
  • Save tokens, or collected names and email addresses, to disk. The report shows the organisation and application names you enter.
  • Load external resources from the report.
  • Present a missing figure as measured, or improve a status when a check is skipped.

What you get

One self-contained HTML report in English or German, ready to save, read offline or print.

  • Report details

    Date, data source and target profile, at the top of every report.

  • What we found

    What the available evidence shows about your use of Microsoft 365.

  • Five-year cost comparison

    Compare staying, a partial move and a full move at the prices you enter. The figures include retained licences, project costs, lost working time and parallel running.

  • Readiness by area

    Ready, Needs work, Blocker or Unknown, with reasons, evidence and what was left unexamined.

  • What moves where

    Possible replacements under the chosen target profile, with documented gaps.

  • Needs attention

    File types to review, Windows-only applications and functions that may not carry over directly.

  • Suggested path

    Blockers, open questions and the areas that pass the current checks.

  • Appendix

    Collection methods, rules, mappings, cost calculations and run details.

Install Git and uv, then run three commands. The first run downloads what Fazit needs; after that the demo runs offline in about a second, with no Microsoft account.

Get started

Reading the findings

Each finding shows its source, date, reporting period and coverage where available. Inventory figures say whether they were measured, provided or are unknown; cost figures say whether they were entered or calculated. Missing evidence comes with a reason and a next step. Cost totals stay unknown when required amounts are missing.

The report gives a status per area and has no overall score or verdict.

Fazit checks the structure of its inputs and selected relationships between figures. It cannot establish that a supplied inventory is true: a report is only as reliable as the people and tools that supplied its evidence.

Project status

  1. Now

    Run from source. Fazit builds reports from the bundled samples, with your own answers and costs. The measured figures in the samples are simulated. It is not yet on PyPI.

  2. Next

    Import CSV exports from the Microsoft 365 admin centre on your computer, keeping only aggregates, and show where your tenant’s data is stored.

  3. Then

    Install with one command, or on Windows run a signed program without Python. Each release lists its checksums and contents.

  4. After that

    Microsoft 365 Copilot and Copilot Studio as an assessed area, the date by which you need to decide, an export for project plans, a check that a report has not changed, and links to the sovereignty criteria of ZenDiS, the federal centre behind openDesk.

  5. Later

    Sign in read-only to check permissions and count licences and directory entries.

Reports are in German and English. French and Italian are planned with the Swiss pilot; the translation guide shows how to add a language.

How it is made

Written with AI tools, directed by a person.

Claude and Codex write the code. The maintainer decides what is built and answers for it, without reading every line. Before each release, other models look for faults, and their findings are public.
