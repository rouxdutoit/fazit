Fazit

Assess a move from Microsoft 365

A free, open source tool that shows what your organisation relies on, what needs work and how the costs compare. It creates the report on your computer.

View sample report Source code

Try the demo from source

git clone https://github.com/rouxdutoit/fazit && cd fazit && uv run fazit demo

What you get

One self-contained HTML report in English or German, ready to save, read offline or print.

Report details
The header records the date, source and target profile. The footer identifies Fazit.
Inventory
What the available evidence shows about your use of Microsoft 365.
Five-year costs
Compare staying, a partial move and a full move. The figures include retained licences, project costs, lost working time and parallel running.
Readiness by area
Ready, Needs work, Blocker or Unknown, with reasons, evidence and what was left unexamined.
What moves where
Possible replacements under the chosen target profile, with documented gaps.
What needs attention
File types to review, Windows-only applications and functions whose direct transfer is unverified.
Suggested path
Blockers, questions to resolve and areas that may be suitable for a pilot.
Appendix
Collection methods, rules, mappings, cost calculations and run details.

How it works

  1. Set up

    Install Git and uv. The first run downloads the Python dependencies. The demo runs without a Microsoft account.

  2. Run the demo

    Use the command above for the town sample in English. In the clone, run uv run fazit demo --lang de for German.

  3. Open the report

    Open the HTML file named on the last line. The report shows the evidence for each finding and what to check next.

What Fazit never does

  • Write to a Microsoft tenant or call an endpoint outside the read allowlist.
  • Send assessment data off your computer. The current version contacts no host. Live sign-in and collection will be limited to Microsoft sign-in and Graph.
  • Save tokens or collected names and email addresses to disk. The report can show the organisation and Windows-only application names you enter.
  • Load external resources from the report.
  • Invent results or improve a status when a check is skipped.

Check it yourself

After the first run, disconnect from the network. Run uv run --offline fazit demo and open the report in your browser.

How to verify offline operation

Reading the findings

Each finding shows its source, date, reporting period and coverage where available. The report marks figures as measured, provided or unknown. Missing evidence comes with a reason and a next step. Cost totals stay unknown when required amounts are missing.

The report gives a status per area and has no overall score or verdict. Your organisation decides whether to move.

An internally consistent fabrication can pass Fazit’s checks, so the report depends on the people and tools that supplied the evidence.

Built on

  • openDesk evaluation for the City of Zurich Bern University of Applied Sciences
  • Alternatives to Microsoft 365 and the implications of switching (PDF) Study for Digitale Verwaltung Schweiz

Target projects

The openDesk and Nextcloud profiles describe functions covered by projects such as Collabora Online, Open-Xchange, Element, Jitsi and Keycloak. Use the generic profile to consider other setups, such as desktops with Linux and LibreOffice.
