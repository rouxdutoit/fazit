Befund

See what leaving Microsoft 365 would take, on your own machine.

A free, open source command-line tool licensed under AGPL-3.0-or-later.

View the sample report Source code

After publication on PyPI

$ uvx befund demo

Early release. The demo works today; assessing a real organisation comes next.

What you get

Befund writes a single HTML report in German or English. You can save it, share it and open it offline.

Inventory
What the available data shows about your use of Microsoft 365 across 15 areas, from email and files to telephony, device management and business application integrations.
Readiness
Each area is marked Ready, Needs work, Blocker or Unknown. The report gives the evidence for each status.
Possible replacements
Which functions could move to open source software and which dependencies need attention first.
Five-year costs
Compare staying with Microsoft 365, moving some areas and moving all areas. The comparison includes retained licences, project costs, productivity losses and parallel running.

How it works

  1. Install

    Install uv. Once the package is published, uvx can download Befund and its dependencies on the first run.

  2. Run

    From a local copy of the source, run uv run befund demo --lang en to try the bundled sample. Use --lang de for German.

  3. Read the report

    Open the HTML file on your computer. The report shows what was checked and what is still unknown.

Inputs

Available now
Bundled sample data.
Planned next
Files exported from the Microsoft 365 admin centre, processed locally.
Planned later
Read-only sign-in to Microsoft 365.

What it never does

  • Befund has no write access to Microsoft 365.
  • Assessment data stays on your computer. There is no Befund server, account or telemetry.
  • Befund never stores sign-in tokens on disk.
  • The report contains no personal names or email addresses.
  • The report loads nothing from the internet when you open it.

Check it yourself

Once the demo is set up, disconnect from the network. Run the demo again and open the report in your browser.

What it claims, and what it does not

What the evidence shows

Befund reports what it can establish and gives a status per area. Findings include the source, date, reporting period and coverage, with a reason where evidence is missing. Each figure is marked as measured, supplied by your organisation or unknown. A skipped check never improves a status.

Where the evidence stops

Your organisation decides whether to leave Microsoft 365. Befund gives no overall go or no-go verdict. When an area is not yet ready, the report shows what needs attention.

Cost totals stay unknown if key figures from your organisation are missing. File names can flag documents for review. Confirming macros requires looking inside the file.

Built on

Two public evaluations inform the structure of the assessment.

  • openDesk evaluation for the City of Zurich Bern University of Applied Sciences
  • Alternatives to Microsoft 365 and the implications of switching (PDF) Study for Digitale Verwaltung Schweiz

Open source projects

Befund maps Microsoft 365 functions to potential replacements in openDesk, Nextcloud, LibreOffice, Collabora, Open-Xchange, Element, Jitsi and Keycloak.

Status

  • Now. The demo produces an offline report from bundled sample data in German or English. The PyPI release is pending.
  • Next. Assess an organisation using its exported usage reports.
  • Later. Check permissions and collect licence and directory counts through a read-only sign-in.

Founding pilots

We offer three free pilot assessments for organisations with 200 to 2,000 staff, one each in Germany, Austria and Switzerland.

Your data stays with your organisation. You decide separately whether we may name your organisation publicly. Taking part carries no obligation to buy anything or to migrate.

Public bodies receive a one-page agreement for their approval process.
