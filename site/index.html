Find the blockers before the project does

Many public bodies and companies are weighing a move away from Microsoft 365, for digital sovereignty, data protection or cost. Few can say exactly what they depend on.

So projects find the hard parts halfway through, such as telephony or hundreds of business-critical macros. Once local import is available, Fazit will help you find those dependencies before the project starts. The report already shows the evidence for each finding and marks missing evidence as “Unknown”.

It gives no overall score and recommends no supplier. Your organisation decides whether to move, what to move and when.

Private by design

Fazit creates the report locally, and the current version makes no network connections at all. Keep the scan, inputs and report on local storage and your data stays on your computer.

  • Runs on your computer

    The report is a single file on your own disk. Nothing is uploaded, and there is no account or cloud service.

  • No network connections

    The current version contacts no server. A planned read-only sign-in will talk only to Microsoft sign-in and Microsoft Graph.

  • Read-only

    Fazit never writes to Microsoft 365 and keeps no tokens, personal names or email addresses.

  • Open to inspection

    Every safeguard has a test anyone can run. Disconnect from the network and the demo still works.

What Fazit never does

  • Write to a Microsoft tenant or call an endpoint outside the read allowlist.
  • Send assessment data off your computer. The current version contacts no host. The planned read-only sign-in will only talk to Microsoft sign-in and Microsoft Graph.
  • Save tokens or collected names and email addresses to disk. The report can show the organisation and Windows-only application names you enter.
  • Load external resources from the report.
  • Invent results or improve a status when a check is skipped.

What you get

One self-contained HTML report in English or German, ready to save, read offline or print.

  • Report details

    Date, data source and target profile, at the top of every report.

  • What we found

    What the available evidence shows about your use of Microsoft 365.

  • Five-year cost comparison

    Compare staying, a partial move and a full move. The figures include retained licences, project costs, lost working time and parallel running.

  • Readiness by area

    Ready, Needs work, Blocker or Unknown, with reasons, evidence and what was left unexamined.

  • What moves where

    Possible replacements under the chosen target profile, with documented gaps.

  • Needs attention

    File types to review, Windows-only applications and functions that may not carry over directly.

  • Suggested path

    Blockers, questions to resolve and areas that may be suitable for a pilot.

  • Appendix

    Collection methods, rules, mappings, cost calculations and run details.

How it works

Try the demo from source

git clone https://github.com/rouxdutoit/fazit && cd fazit && uv run fazit demo

  1. Set up

    Install Git and uv. The first run downloads the Python dependencies.

  2. Run the demo

    Use the command above for the town sample in English. In the clone, run uv run fazit demo --lang de for German.

  3. Open the report

    Open the HTML file named on the last line of the output. The report shows the evidence for each finding and what to check next.

Reading the findings

Each finding shows its source, date, reporting period and coverage where available. The report marks figures as measured, provided or unknown. Missing evidence comes with a reason and a next step. Cost totals stay unknown when required amounts are missing.

The report gives a status per area and has no overall score or verdict. Your organisation decides whether to move.

Fazit checks its inputs for contradictions, but it cannot detect a fabrication that is consistent. A report is only as reliable as the people and tools that supplied its evidence.

Project status

  1. Now

    Run from source. Fazit builds reports from the bundled samples, with your own answers and costs. Measured figures come from the samples until import arrives. It is not yet on PyPI.

  2. Next

    AI assistants such as Microsoft 365 Copilot and Copilot Studio become an assessed area. The report shows when your licences renew and by when you need to decide.

  3. Then

    An export of the findings for project plans, a check that a report has not been changed, and a link from each finding to the sovereignty criteria of ZenDiS, the federal centre behind openDesk.

  4. After that

    Import CSV exports from the Microsoft 365 admin centre on your computer, keeping only counts, and show where your tenant’s data is stored.

  5. Later

    Sign in read-only to check permissions and count licences and directory entries.

French and Italian are planned with the Swiss pilot. Fazit is built to be translated; the guide explains how.
