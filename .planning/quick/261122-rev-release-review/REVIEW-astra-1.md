# Fazit release review

## Verdict

**Release after fixes.** A denied directory check turns four unknowns into Ready, and the report can recommend an integrations pilot even when the service owner has reported dependent applications.

- Remove report font encoding at `report.py:372` and the two font-face blocks at `templates/report.html.j2:165`. About **20 lines**, two packaged binaries and **68,700 base64 characters per report** go away.
- Separate product classification at `rules.py:402` from rule-file validation and readiness decisions. Build the SKU and plan lookup once for classification, public JSON at `model.py:578` and display at `report.py:198`. About **10–20 repeated lines** can go. Keep the distinct privacy check on unregistered identifiers. The cost formulas already have a clear home in `costs.py`.
- Move the test-only `SECTION_ORDER` at `report.py:40` into shared test data. Replace its duplicate nine-item literal at `tests/test_cli.py:49` with that expectation. Save about **10 lines** while still checking the rendered order. In `tests/test_report.py:220`, exercise the invariant stylesheet once and keep the multilingual layout and resource checks on generated reports.

## What is good and must not be lost

- Both demos opened offline in Chromium at 360 px with zero HTTP requests and no horizontal overflow. Text labels accompany status symbols. The installed-wheel socket audit covers the actual console entry point.
- I recalculated the town example in euros. Staying is 5 × (100,000 + 20,000) = **600,000**. Partial exit retains 60,000 × 54/12 in licences and adds 8.50 × 30 × 60 in hosting, 137,500 other running costs, 46,000 project, 9,000 productivity loss and 50,000 overlap = **527,800**. Full exit gives 8.50 × 85 × 60 hosting + 170,000 other running costs + 126,000 project + 25,000 loss + 100,000 overlap = **464,350**. Differences from staying are **−72,200** and **−135,650**. The nonprofit’s missing productivity cost correctly leaves its full-exit total unknown.
- All **1,343** product/plan pairs across the 52 registered SKUs matched Microsoft’s downloadable reference, including the EEA SKU with nonbreaking spaces. Preserve the matching by both name and GUID. [Microsoft licensing reference](https://learn.microsoft.com/en-us/entra/identity/users/licensing-service-plan-reference)
- Duplicate keys, non-finite numbers, invalid UTF-8, malformed files and oversized input gave short errors. All 16 registry entries in the lockfile have hashes and predate uv’s 7 November cutoff. The build backend is pinned exactly and CI uses read-only permissions and action SHAs. The age cutoff protects the checkout installation. The built wheel declares dependency lower bounds.

I ran `uv sync`, both language demos, both sample rebuilds, all three profiles, both Ruff checks, `uv run pytest -q` (**586 passed**) and `uv run python site/check_site.py` (**16 pages, 497 references**). Browser checks used the repository’s hosting headers. The Frankfurt storage location, European delivery region, three-day deletion and signed DPA stated at `site/privacy/index.html:81` require confirmation from the operator’s hosting records.

## Ideas

- Give a council officer a one-page print summary with the first blocker, outstanding questions and three scenario totals. The town report printed to 29 English or 31 German A4 pages in Chromium. Size the headline cards for German labels as well. On page one, “Postfächer” leaves its final letter on a line of its own.
- Supply a blank interview starter with every measurement unknown. An integrator can enter a client’s figures without carrying the fictional town’s inventory into the meeting.
- Ask each pilot’s IT officer to trace one status and recalculate one cost unaided. Their answers will show which explanations let a decision-maker independently check the report.
- Set the README and project URLs in `pyproject.toml:2` before publishing. The built package metadata has an empty long description and no project URL, leaving a PyPI visitor without the demo or source link.
