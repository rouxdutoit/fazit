## 1. Top comments

1. **“I have a Microsoft 365 admin-centre export on my desktop. Which command takes it?”**  
   **Fair.** The CLI exposes `demo` and `report`. The latter expects Fazit’s JSON format, and every registered source of measured inventory is a sample source. The README discloses this. The homepage makes the reader scroll to find it. Put “Today’s version builds reports from fictional inventory” above the first button. Ship local CSV import before announcing an assessment tool. [CLI commands](../../../src/fazit/cli.py:88) · [Accepted sources](../../../src/fazit/rules/findings.yaml:358) · [Homepage disclosure](../../../site/index.html:358)

2. **“I followed the ‘use your own answers’ instructions, entered my council’s name, and now we have 91 mailboxes. That’s an unfortunate document to put in front of a committee.”**  
   **Fair.** I reproduced this. The header says the measurements are simulated, but a cropped inventory card says **Measured**, and the real organisation name appears above it. Give the own-answers walkthrough an empty inventory so every unavailable measurement stays Unknown. Reserve the fictional town scan for the demo walkthrough. [README walkthrough](../../../README.md:39) · [Sample header and inventory](../../../site/demo/en/index.html:291)

3. **“I switched from openDesk to Nextcloud to a target I haven’t even chosen. All fifteen readiness ratings stayed the same. What exactly am I ready for?”**  
   **Fair.** I regenerated all three profiles. Every town workload kept its status. The target changes the function mappings. The readiness evaluator receives no target argument. Licences can be Ready once products are recorded and terms reviewed, even if those terms make an exit impractical. Only one shipped rule can produce Blocker, and it concerns telephony. Put both limits beside the status legend. [Evaluator call](../../../src/fazit/report.py:307) · [Licence rule](../../../src/fazit/rules/status.yaml:3) · [Only Blocker rule](../../../src/fazit/rules/status.yaml:236)

4. **“I know the names and effort settings of four models. I still don’t know who with Microsoft migration experience reviewed the advice.”**  
   **Fair on the evidence.** The repository identifies a responsible maintainer and publishes model reviews. Neither establishes that a practitioner checked the judgement rules against a migration. Replace the model cards with one authorship sentence. For the rules, publish who reviewed which version and what they changed, or state that field validation is pending. [Homepage credits](../../../site/index.html:388) · [Development account](../../../.planning/PROJECT.md:71)

5. **“I entered ten devices, twenty of them Windows. It printed both numbers.”**  
   **Fair.** With an empty scan and both counts in the same dated `inputs.yaml`, the renderer accepted exactly that. This is an ordinary data-entry error, and it survives a feature advertised as checking contradictions. Validate the Windows subtotal against the total when both describe the same inventory, and add that case to the tests. [Advertised check](../../../README.md:53) · [Device fields](../../../src/fazit/rules/findings.yaml:246)

6. **“Once I’ve priced the licences, hosting, migration, training and lost productivity myself, what have I learned that `SUM()` wouldn’t tell me?”**  
   **Fair about the cost claim.** Fazit handles parallel running, retained licences and missing amounts. It does not derive migration effort from the inventory. The town’s €135,650 full-exit saving disappears if annual target operations rise from €12,000 to €39,130, with every other input fixed. Put that one-line sensitivity example beside the sample total. It explains exactly what the calculation contributes. [Sample assumptions](../../../src/fazit/demo/town/inputs.yaml:29) · [Displayed saving](../../../site/demo/en/index.html:2692)

7. **“Our payroll workbook is an old `.xls`. Your homepage talks about hundreds of business-critical macros, but that extension isn’t even on your list.”**  
   **Fair.** The sample’s 271 is a supplied count of files that *may* contain macros. The v1 roadmap has no source for file-type counts, and legacy `.xls` can contain VBA. Include it among formats requiring review, and say that an operator supplies the counts. Neither change requires opening a document. [Homepage claim](../../../site/index.html:91) · [Extension list](../../../src/fazit/rules/risky_file_types.yaml:10) · [v1 limit](../../../.planning/ROADMAP.md:144) · [Microsoft’s XLS specification](https://learn.microsoft.com/en-us/openspecs/office_file_formats/ms-xls/884177af-9129-44ce-a21a-e561b5950f52)

   **Fair.** The cited guide establishes that a transfer method was undocumented there. The openDesk mappings for SharePoint workflows and VBA have no field connecting either need to an answer, so both remain Unknown after the interview. Use “Direct transfer undocumented” for those rows and add the two yes/no/unknown interview fields.     **Partly fair.** A developer can run it from source, and CI includes Windows. The published command uses `&&`, introduced in PowerShell 7. There is no tagged installer in the checkout. Split the three commands onto separate lines now. Give the intended operator the signed executable already specified for launch. ## 5. Launch timing

**Wait.** The strongest reason is the project’s own launch gate: local import, phase 2.1 distribution and final review precede Show HN. Honour it. Fix the two device judgements, make the own-answers walkthrough safe to forward, and have one target operator complete the export-to-report path unaided. Then link directly to the runnable example and have the maintainer describe, in their own words, one decision it helped someone make and one dependency it missed. Live Graph sign-in can come later. HN welcomes early software people can try. Today, readers can try the renderer, while the headline invites them to try an assessment.
