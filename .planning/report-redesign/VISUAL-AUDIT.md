# Visual audit

## Scope

The audit covers all 20 website pages, including both 404 pages, and both sample reports. Playwright Chromium captured 132 views per pass at 360, 768 and 1280 px, in light and dark mode. Each capture is 800 px high, with at least 96 px of overlap between successive views and the final view aligned to the bottom. The website used its normal JavaScript. The reports opened as local HTML files in an offline context with JavaScript disabled.

The review used [DESIGN.md](../../DESIGN.md), the [report UI specification](UI-SPEC.md) and the [RR-09 summary](RR-09-SUMMARY.md). Apple’s guidance informed the checks for alignment, the reading order and visible keyboard focus. [Layout](https://developer.apple.com/design/human-interface-guidelines/layout), [Typography](https://developer.apple.com/design/human-interface-guidelines/typography), [Focus and selection](https://developer.apple.com/design/human-interface-guidelines/focus-and-selection).

The [before index](../../.shots/visual-audit/before/index.json) and [after index](../../.shots/visual-audit/after/index.json) list the route, viewport, theme and scroll position of each screenshot. Files are under `.shots/visual-audit/{before,after}/<route>/<width>-<theme>/`. The contact sheets place light and dark views side by side. [Before sheets](../../.shots/visual-audit/before-sheets/), [after sheets](../../.shots/visual-audit/after-sheets/).

## Verification

I reviewed 1,008 viewport captures before and 984 after, plus 236 keyboard and disclosure captures on each pass. All 132 final views fit the viewport width. The site menu passed keyboard checks for entry, every link, exit and Escape. The report skip link, contents and filter and evidence controls showed visible focus. The lowest sampled report contrast was 4.66:1 for text and 3.06:1 for the status symbols.

Both sample reports opened offline with JavaScript disabled. The report interactions passed in that context. In A4 print, the opening summary occupied page one and the detailed sections followed, with or without background graphics.

Both bundled sample reports were regenerated. The eight homepage previews were rebuilt with the RR-05 crop recipe. Each shows the four status counts and the full Telephony blocker. The English and German alt text still describes the images. [Preview recipe](RR-05-PLAN.md), [preview dimensions and file sizes](../../.shots/visual-audit/previews.log).
