# Directory card names the wrong missing evidence

Since rv16, Directory needs a passed licence check. When the check is open, the card asks "What does the evidence show for 'Licensed accounts'?" and says "The scan does not include this finding", while listing that count as measured and complete. What is missing is the licence inventory. German reads the same way. Name the licence inventory (or the reconciliation) as the open question, in both locales.
