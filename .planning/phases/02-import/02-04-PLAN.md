## Roster file shape

`src/fazit/rules/products.json` (JSON has no comment syntax, so no SPDX line, as for the sample scans):

```json
{
  "source": {
    "url": "https://download.microsoft.com/download/e/3/e/e3e9faf2-f28b-490a-9ada-c6089a1fc5b0/Product%20names%20and%20service%20plan%20identifiers%20for%20licensing.csv",
    "reference_url": "https://learn.microsoft.com/en-us/entra/identity/users/licensing-service-plan-reference",
    "downloaded_on": "YYYY-MM-DD",
    "sha256": "<64 lower-case hexadecimal characters>",
    "counts": {"rows": 0, "products": 0, "plans": 0},
    "attribution": "Identifiers and names from Microsoft's \"Product names and service plan identifiers for licensing\" (https://learn.microsoft.com/en-us/entra/identity/users/licensing-service-plan-reference), generated by scripts/generate_product_roster.py. Microsoft's CSV is not redistributed."
  },
  "products": [
    {"guid": "<lower-case GUID>", "string_id": "<String_Id>", "display_names": ["<name>", "..."], "plans": ["<plan GUID>", "..."]}
  ],
  "plans": [
    {"guid": "<lower-case GUID>", "names": ["<canonical name>", "<other names>"], "friendly_names": ["<friendly name>", "..."]}
  ]
}
```

Products and plans are sorted by GUID; `display_names`, `plans` and `friendly_names` are sorted and unique; `names` holds the canonical name first and the others sorted. The file is written with `json.dumps(..., ensure_ascii=False, indent=1, sort_keys=True)` and one trailing newline.
