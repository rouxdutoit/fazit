## Goal

Every imported figure can be traced to the file it came from without the scan ever storing a file name: the scan records each export by checksum, the report lists those checksums, and `fazit import` prints the same ones. Tests prove that names stay out and that the installed tool imports with no network.

Task 3 adds the privacy import case, the installed-package offline run and the `.gitattributes` exceptions the later fixture plans need.

Output: model and serialisation changes, concealment detection, an appendix table, locale strings, a documentation section, a decision entry, tests.
