# Plan 02-00: the founder records real export headers (human step)

## Goal

Microsoft documents the Graph CSV headers of the usage reports, but not the bytes the admin-centre Export button writes, and it documents no layout at all for the licence list, the Exchange mailbox list and the Entra downloads. This plan records, from a real tenant, only what the importer needs to recognise those files: header lines and format facts, in English and in German. Nothing from the tenant itself is written down.

<objective>
The founder exports nine files from a Microsoft 365 tenant, once with the admin centre in English and once in German, and fills `.planning/phases/02-import/02-HEADERS.md` from the template in this plan (D-116). The coordinating session then runs the completeness and privacy check (Task 3).

This plan is not run by Codex and changes no code, so it does not wait for the report redesign merge (D-91) and has no code precondition. It runs in parallel with plan 02-01 and the plans after it; the first plan that needs it is 02-06 (observed headers for the usage layouts), which runs as soon as this file and plan 02-05 exist. Plans 02-06, 02-11, 02-12, 02-13 and 02-14 read `02-HEADERS.md` first and stop if it is missing or incomplete.

Purpose: the licence, mailbox-list and Entra layouts are built only from this observation, and the usage layouts are corrected from it (D-116, research assumptions A1 to A5).
Output: one Markdown file in the phase directory. No code, no fixture, no tenant data.

Run order of the phase: 02-00 and 02-01 (wave 1); 02-02 (wave 2); 02-03 and 02-04 (wave 3); 02-05 (wave 4); 02-06 and 02-07 (wave 5); then one plan per wave: 02-08, 02-09, 02-10, 02-11, 02-12, 02-13, 02-14 (waves 6 to 12). From wave 6 on, each wave holds one plan because every one of them changes a rule file whose checksum appears in the demo report or builds on the plan before it.
</objective>

- Work in a folder outside the repository and delete the downloaded files when you are done. Do not open the files in Excel: Excel changes delimiters, dates and numbers. Use a text editor or the commands below.

Commands that read only the first bytes or the first line of a file (replace FILE):
- macOS or Linux: `head -c 4 FILE | od -An -tx1` (first bytes); `head -n 1 FILE` (header line); `file FILE` (shows "with CRLF line terminators" for CRLF); for a UTF-16 file: `iconv -f UTF-16 -t UTF-8 FILE | head -n 1`.
- Windows PowerShell: `Format-Hex -Path FILE -Count 4` (first bytes); `Get-Content FILE -TotalCount 1` (header line; PowerShell detects UTF-16 by its BOM); `(Get-Content FILE -Raw) -match "\r\n"` (True for CRLF).
