# Plan 02-10: data location and EU Data Boundary as provided facts

## Goal

Data protection officers and staff representatives ask first where the data is stored. The report states the tenant's data location and its EU Data Boundary status as plain facts with where they came from and when, and says exactly what to supply when nobody has answered.

<objective>
Built on the report redesign merged into main (D-91). Task 1 checks it and stops if it is missing.

Task 1 registers the geography codes and reads the answers from `inputs.yaml`. Task 2 shows the facts in the report header. Task 3 brings the example file, both interview checklists and the town sample into line and proves that no status changes.

Purpose: DATA-01 as decided in D-112 and D-129: no admin-centre export carries these facts (research section 6), so they are provided answers with registered codes.
Output: catalogue codes and loader, inputs field, header facts, locale strings, example and checklist lines, sample answers, tests, regenerated site demo reports.

Run order of the phase: 02-00 and 02-01 (wave 1); 02-02 (wave 2); 02-03 and 02-04 (wave 3); 02-05 (wave 4); 02-06 and 02-07 (wave 5); then one plan per wave: 02-08, 02-09, 02-10, 02-11, 02-12, 02-13, 02-14 (waves 6 to 12). This plan needs no import code; it follows 02-09 only because both change rule files and the site demo reports.
</objective>
