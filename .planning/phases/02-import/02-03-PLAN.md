# Plan 02-03: real-world files: encodings, delimiters, refusals and concealment variants

## Goal

The officer's files are rarely the textbook case: some were opened and saved in German Excel, some are UTF-16, some carry the wrong report, two files may be the same export, and a fresh report may have no rows yet. Each of these imports or is refused with a sentence that names the file and says what to do, and one bad file never stops the others.

Task 1 hardens reading and values. Task 2 handles recognition across files: closest layout with missing columns, duplicates, directories, empty exports, and the "nothing recognised" stop. Task 3 adds the fixture variants with their README entries and the property and privacy tests over them.

Purpose: IMPT-04 and the D-101/D-126 encoding rules, on the one export that exists so far; plans 02-05 and later reuse all of it for their layouts.
Output: changes to the five import modules, boolean spellings in `rules/exports.yaml`, new locale sentences, eight fixture variants and the committed planted file, tests. No rule file the report reads changes, so the demo reports stay byte-identical.
