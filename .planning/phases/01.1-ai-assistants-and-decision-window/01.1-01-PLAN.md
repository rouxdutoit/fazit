# Plan 01.1-01: the AI assistants area from answers, rules and mappings

## Phase Goal

The report shows an organisation's dependency on Microsoft's AI assistants and tells it when it has to decide before its licences renew.

> This is the ROADMAP.md goal line for Phase 1.1, copied as written.

<objective>
Add the area `copilot` ("AI assistants (Copilot)" / "KI-Assistenten (Copilot)") as the second area everywhere in the report, judged by status rules per D-84 from provided answers and the licence signal the engine already derives, mapped for the three target profiles per D-88, asked about in the example file and both interview checklists, and answered in both samples.

Purpose: AIAS-01. Organisations now depend on Copilot and agents in ways no other area captures; the report must say so with the same honesty rules as every other area, so missing answers read Unknown and never Ready.
Output: data changes in the catalogue, status rules, three mappings, two locales, the example file, two checklists and two sample answer files; tests for every status; regenerated site demo reports.

This is plan 1 of 4. Plan 01.1-02 adds the Copilot products to the licence catalogue, so a paid add-on becomes measured evidence. Plan 01.1-03 adds the decision window and depends on this plan only. Plan 01.1-04 publishes the site and README changes. Until plan 01.1-02 runs, no Copilot product is in `rules/service_plans.yaml`, so `copilot.licence_add_on_assigned` is derived as measured false for both samples; the rules written here already use it.
</objective>
