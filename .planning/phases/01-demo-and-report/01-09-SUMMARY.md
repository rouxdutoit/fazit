# Plan 01-09 summary

A02 checks the catalogue bindings for findings used by the workload's rules. A skipped or partial collector leaves a gap even when its finding is omitted or a manual answer supplies the value. The report gives the collector, reason and next step. Confirmed problems still set the workload status.

A03 registers licence inventory sources in `findings.yaml` under `codes.licence_sources`. The scan loader rejects other sources at `licences.source`. An empty licence inventory leaves the product count and every workload's licence signals unknown with `licence_products_missing`. A partial licence collector can establish assignments that were observed and leaves unconfirmed assignments unknown.

An unclassified plan on any assigned product leaves unconfirmed licence signals unknown across all workloads. Classified assignments still establish presence. The report counts unclassified plans per product and asks the reader to update the service plan catalogue. Both site reports were regenerated.

## Public interfaces

- `catalogue.load_catalogue(path: Path | None = None) -> Catalogue` returns a frozen catalogue with `workloads: tuple[WorkloadEntry, ...]`, `findings: tuple[FindingEntry, ...]`, `collector_ids`, `source_codes`, `reason_codes`, `permissions`, `provided_sources` and `licence_sources` as `frozenset[str]`, `sku_exceptions: frozenset[tuple[str, str]]`, `file_name: str` and `checksum: str | None`. `source_codes` includes the licence and provided source registries. The catalogue exposes `workload_ids: tuple[str, ...]`, `finding(finding_id: str) -> FindingEntry | None` and `accepts_sku_part_number(part_number: object, guid: str) -> bool`. The frozen entries are `WorkloadEntry(id: str, label: str)` and `FindingEntry(id: str, workload: str, type: str, unit: str | None, label: str, provided: str, headline: bool, measured_by: frozenset[tuple[str, str]] = frozenset())`. `measured_by` holds allowed collector and source pairs.
- `model.load_scan(path: Path, catalogue: Catalogue) -> Scan`, `load_scan_text(text: str, file_name: str, catalogue: Catalogue) -> Scan` and `scan_to_json(scan: Scan, *, plans: tuple[rules.ServicePlan, ...]) -> str` handle scan I/O. The frozen `Scan(schema_version: str, tool: ToolInfo, generated_at: str, source_kind: str, collectors: tuple[Collector, ...], findings: tuple[Finding, ...], licences: Licences | None, dropped_count: int = 0)` exposes `finding(finding_id: str) -> Finding | None` and `collector(collector_id: str) -> Collector | None`. `dropped_count` is internal to the loader and renderer. `ToolInfo(name: str, version: str)`, `Collector(id: str, status: str, reason: str | None, permissions_used: tuple[str, ...])` and `Coverage(kind: str, scanned: int | None = None, failed: int | None = None, total: int | None = None)` are frozen.
- The frozen `model.Finding(id: str, workload: str, value: FindingValue | None, unit: str | None, provenance: str, collector: str | None, source: str | None, collected_at: str | None, period: str | None, coverage: Coverage | None, missing_reason: str | None)` uses `FindingValue = int | bool`. The other frozen evidence records are `Licences(collector: str, source: str, collected_at: str, coverage: Coverage, products: tuple[Product, ...])`, `Product(sku_part_number: str | None, sku_guid: str | None, purchased: int, assigned: int, service_plans: tuple[model.ServicePlan, ...])` and `model.ServicePlan(name: str | None, guid: str | None)`. `Product.key` is a `tuple[str, str] | None`.
- `rules.load_service_plans(catalogue: Catalogue, path: Path | None = None, *, checksums: MutableMapping[str, str] | None = None) -> tuple[ServicePlan, ...]` reads the classification records. The frozen `rules.ServicePlan` has `sku_part_number`, `sku_guid`, `name`, `guid`, `signal` and `reference_url` as strings, `workload: str | None`, `checked_on: date` and `note: Mapping[str, str] | None`. `classify_product(product: model.Product, plans: tuple[ServicePlan, ...]) -> tuple[ServicePlan | None, ...]` returns matches in observed order. `licence_findings(scan: Scan, plans: tuple[ServicePlan, ...], catalogue: Catalogue) -> tuple[Finding, ...]` returns `licences.product_count` first, then the add-on and bundled assignment findings in catalogue workload order. A missing licence block yields an empty tuple.
- `rules.load_status_rules(catalogue: Catalogue, path: Path | None = None, *, checksums: MutableMapping[str, str] | None = None) -> StatusRuleSet`. `evaluate(findings: Mapping[str, Finding], rule_set: StatusRuleSet, catalogue: Catalogue, *, collectors: Mapping[str, Collector] | None = None, alternatives: Mapping[str, Finding] | None = None) -> tuple[WorkloadStatus, ...]` uses the supplied collectors by ID and alternate observations by finding ID. The frozen `WorkloadStatus(workload: str, status: str, reason_code: str | None, missing: tuple[MissingEvidence, ...], deciding: StatusRule | None, notes: tuple[StatusRule, ...], evidence: tuple[Finding, ...])` exposes `incomplete: bool`. Each frozen `MissingEvidence(finding_id: str, reason_code: str, collector: str | None)` can identify a bound collector even when the scan omits its finding.
- `inputs.load_inputs(path: Path, catalogue: Catalogue) -> Inputs`, `load_inputs_text(text: str, file_name: str, catalogue: Catalogue) -> Inputs`, `provided_findings(inputs: Inputs, catalogue: Catalogue) -> tuple[Finding, ...]` and `combine(scan: Scan, provided: tuple[Finding, ...]) -> tuple[Scan, tuple[Finding, ...]]` handle manual evidence. The frozen `Inputs` holds `organisation_name`, `currency`, `language`, `target_profile` and `as_of` as optional strings, `amounts_are_invented: bool`, `answers_are_sample: bool`, `current_costs: CurrentCosts`, `partial_exit: ScenarioInputs`, `full_exit: ScenarioInputs`, `windows_only_software: tuple[WindowsSoftware, ...] | None`, `provided_counts: Mapping[str, int | None]` and `confirmations: Mapping[str, bool | None]`.
- `report.render_report(scan: Scan, *, lang: str, profile: str = "opendesk", catalogue: Catalogue | None = None, inputs: Inputs | None = None) -> str`, `render_demo(scan: Scan, *, lang: str, profile: str, catalogue: Catalogue, inputs: Inputs) -> tuple[str, str]` and `report_file_name(generated_at: str, *, lang: str) -> str` expose report rendering, the demo HTML and JSON pair, and its date-and-language filename.
- The Typer application is `befund.cli.app` and the console entry point is `befund.cli:main() -> None`. `befund [--debug] demo [--lang en|de] [--sample town|nonprofit] [--profile opendesk|nextcloud|generic] [--out DIR]` defaults to `en`, `town`, `opendesk` and `./report`. `befund [--debug] report SCAN_JSON [--inputs FILE] [--lang en|de] [--profile opendesk|nextcloud|generic] [--out DIR]` resolves language and profile from flags, inputs and defaults. Both commands support `--help` and print the absolute `report-<YYYY-MM-DD>-<lang>.html` path last. Demo also writes `scan-<YYYY-MM-DD>-<lang>.json` and `inputs-<YYYY-MM-DD>-<lang>.yaml`. Global `--version` prints the installed version. Input errors exit 2 with one localized sentence unless `--debug` exposes the exception.
