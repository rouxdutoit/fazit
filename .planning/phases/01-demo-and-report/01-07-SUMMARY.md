## Public interfaces

- `befund` exports `PROJECT_NAME`, `REPOSITORY_URL` and `__version__`. The console entry point is `befund.cli:main`. The module exposes the Typer application `app` and `main() -> None`.
- Top-level usage is `befund [OPTIONS] COMMAND [ARGS]...` with global options `--debug`, `--version` and `--help`. `befund demo [--out DIR] [--lang en|de] [--sample town|nonprofit] [--profile opendesk|nextcloud|generic] [--help]` defaults to `report`, `en`, `town` and `opendesk`. `befund report SCAN_JSON [--inputs PATH] [--lang en|de] [--out DIR] [--profile opendesk|nextcloud|generic] [--help]` requires the scan path and defaults to `report` for output. Report language and profile resolve from flags, inputs, then `en` and `opendesk`. Help is English. Input errors exit 2 with one sentence on stderr in the flag language or English. `--debug` exposes the exception and `--version` prints the version.
- Both commands print the absolute path of `report-<YYYY-MM-DD>-<lang>.html` last. The date comes from the scan. `demo` also writes and names `scan-<YYYY-MM-DD>-<lang>.json` and `inputs-<YYYY-MM-DD>-<lang>.yaml`. `output.write_inside(out_dir: Path, file_name: str, text: str) -> Path` atomically writes under the resolved output directory and refuses linked destinations.
- `errors.InputError(code: str, *, file: str | None = None, field: str | None = None, **details: object)` exposes `code`, `file`, `field` and `details`. `parsing.read_text(path: Path | Traversable) -> str`, `parse_json(text: str, file_name: str) -> object`, `parse_yaml(text: str, file_name: str, *, quoted_fields: tuple[str, ...] = ()) -> object` and `reject_at_signs(value: object, file_name: str, field: str = "$") -> None` support validation.
- `model.load_scan(path: Path, catalogue: Catalogue) -> Scan`, `load_scan_text(text: str, file_name: str, catalogue: Catalogue) -> Scan` and `scan_to_json(scan: Scan) -> str` are the scan I/O. `SCHEMA_VERSION` is `"1.0"` and `FindingValue` is `int | bool | str`. The frozen records are `ToolInfo(name: str, version: str)`, `Collector(id: str, status: str, reason: str | None, permissions_used: tuple[str, ...])` and `Coverage(kind: str, scanned: int | None = None, failed: int | None = None, total: int | None = None)`.
- The remaining frozen model records are `Finding(id: str, workload: str, value: FindingValue | None, unit: str | None, provenance: str, collector: str | None, source: str | None, collected_at: str | None, period: str | None, coverage: Coverage | None, missing_reason: str | None)`, `ServicePlan(name: str, guid: str)`, `Product(sku_part_number: str, sku_guid: str, purchased: int, assigned: int, service_plans: tuple[ServicePlan, ...])`, `Licences(collector: str, source: str, collected_at: str, coverage: Coverage, products: tuple[Product, ...])` and `Scan(schema_version: str, tool: ToolInfo, generated_at: str, source_kind: str, collectors: tuple[Collector, ...], findings: tuple[Finding, ...], licences: Licences | None, dropped_count: int = 0)`. `Scan.finding(finding_id: str) -> Finding | None` and `Scan.collector(collector_id: str) -> Collector | None` look up entries. The JSON omits the internal `dropped_count`.
- `catalogue.load_catalogue(path: Path | None = None) -> Catalogue` returns the frozen `Catalogue(workloads: tuple[WorkloadEntry, ...], findings: tuple[FindingEntry, ...], collector_ids: frozenset[str], source_codes: frozenset[str], reason_codes: frozenset[str], permissions: frozenset[str], file_name: str = "findings.yaml", checksum: str | None = None)`. It exposes `workload_ids: tuple[str, ...]` and `finding(finding_id: str) -> FindingEntry | None`. The frozen entries are `WorkloadEntry(id: str, label: str)` and `FindingEntry(id: str, workload: str, type: str, unit: str | None, label: str, provided: str, headline: bool)`.
- `inputs.empty_inputs() -> Inputs`, `load_inputs(path: Path, catalogue: Catalogue) -> Inputs`, `load_inputs_text(text: str, file_name: str, catalogue: Catalogue) -> Inputs`, `provided_findings(inputs: Inputs, catalogue: Catalogue) -> tuple[Finding, ...]` and `combine(scan: Scan, provided: tuple[Finding, ...]) -> tuple[Scan, tuple[Finding, ...]]` handle manual evidence. The last result contains the evaluation scan and alternate observations.
- Frozen `inputs.Inputs` has `organisation_name`, `currency`, `language`, `target_profile` and `as_of` as optional strings, `amounts_are_invented: bool = False`, `current_costs: CurrentCosts = CurrentCosts()`, `partial_exit: ScenarioInputs = ScenarioInputs()`, `full_exit: ScenarioInputs = ScenarioInputs()`, `windows_only_software: tuple[WindowsSoftware, ...] | None = None`, `provided_counts: Mapping[str, int | None]` and `confirmations: Mapping[str, bool | None]`. Optional strings default to `None` and answer mappings default to empty read-only mappings. The other frozen records are `CurrentCosts(microsoft_licences_per_year: Decimal | None = None, other_it_per_year: Decimal | None = None)` and `WindowsSoftware(name: str, users: int | None = None, vendor_has_web_version: bool | None = None)`.
- Frozen `inputs.ScenarioInputs` has optional integer fields `users`, `training_staff` and `parallel_running_months`, and optional Decimal fields `retained_microsoft_licences_per_year`, `hosting_per_user_per_month`, `operations_per_year`, `other_recurring_per_year`, `one_time_migration`, `application_adaptation`, `external_advice`, `training_days_per_person`, `training_day_rate` and `productivity_loss`. Every field defaults to `None`.
- `report.render_report(scan: Scan, *, lang: str, profile: str = "opendesk", catalogue: Catalogue | None = None, provided: tuple[Finding, ...] = (), inputs: Inputs | None = None, sample_inputs: bool = False) -> str` renders the HTML. `report_file_name(generated_at: str, *, lang: str) -> str` names it. `SECTION_ORDER` holds `header`, `found`, `costs`, `readiness`, `moves`, `attention`, `path`, `appendix` and `footer`.
- `rules.rules_dir() -> Traversable` and `rule_file_checksums(profile: str) -> tuple[tuple[str, str], ...]` expose packaged rule resources. `load_status_rules(catalogue: Catalogue, path: Path | None = None, *, checksums: MutableMapping[str, str] | None = None) -> StatusRuleSet`, `load_service_plans(catalogue: Catalogue, path: Path | None = None, *, checksums: MutableMapping[str, str] | None = None) -> tuple[ServicePlan, ...]`, `load_risky_file_types(catalogue: Catalogue, path: Path | None = None, *, checksums: MutableMapping[str, str] | None = None) -> tuple[RiskyKind, ...]` and `load_mapping(profile: str, catalogue: Catalogue, directory: Path | None = None, *, checksums: MutableMapping[str, str] | None = None) -> Mapping` validate the data files. The returned records are described in the [01-03](01-03-SUMMARY.md) and [01-04](01-04-SUMMARY.md) summaries.
- `rules.classify_product(product: Product, plans: tuple[ServicePlan, ...]) -> tuple[ServicePlan | None, ...]` and `licence_findings(scan: Scan, plans: tuple[ServicePlan, ...], catalogue: Catalogue) -> tuple[Finding, ...]` interpret licence evidence. Here `ServicePlan` is the classification record in `rules`. `evaluate(findings: Mapping[str, Finding], rule_set: StatusRuleSet, catalogue: Catalogue, *, collectors: Mapping[str, Collector] | None = None) -> tuple[WorkloadStatus, ...]` yields frozen `WorkloadStatus(workload: str, status: str, reason_code: str | None, missing: tuple[MissingEvidence, ...], deciding: StatusRule | None, notes: tuple[StatusRule, ...], evidence: tuple[Finding, ...])`, with `incomplete: bool`. A frozen `MissingEvidence(finding_id: str, reason_code: str, collector: str | None)` identifies each gap. `rules.select_evidence(recorded: Finding | None, supplied: Finding) -> Finding`, `evidence_conflicts(measured: Finding, provided: Finding) -> bool` and `mapping_need(finding: Finding | None) -> str` provide evidence selection and transfer-gap needs.
- `costs.compute_scenarios(inputs: Inputs) -> tuple[ScenarioResult, ...]` orders the comparison as stay, partial exit and full exit. Frozen result records are `CostLine(id: str, amount: Decimal | None, missing: tuple[str, ...])`, `CostGroup(id: str, lines: tuple[CostLine, ...], total: Decimal | None, missing: tuple[str, ...])` and `ScenarioResult(id: str, running: CostGroup, blocks: tuple[CostGroup, ...], total: Decimal | None, missing_inputs: tuple[str, ...], difference_to_stay: Decimal | None)`.
- `i18n.load_locale(lang: str) -> dict`, `error_sentence(strings: dict, error: InputError) -> str`, `code_label(strings: dict, group: str, code: str) -> str` and `reason_text(strings: dict, code: str) -> tuple[str, str]` localize text. `Formatter(lang: str)` exposes `strings: dict` and formats `integer(value: int)`, `storage(value: int)`, `date(value: str)`, `period(value: str)`, `money(amount: Decimal, currency: str)` and `number(value: Decimal)`. Each formatter returns `str`.
