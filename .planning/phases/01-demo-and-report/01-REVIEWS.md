## What to delete

- Delete the six-package human approval gate. D-02 and D-03 already approve those dependencies. Keep the lockfile review.
- Delete the arbitrary-row renderer introduced for the `mail.largest_mailboxes` fixture. A typed opt-in fixture can exercise both privacy paths.
- Delete the 50% threshold for recommending a move. Keep the descriptive workload-count bar.
- Delete the numeric-literal whitelist and stale `[HEAD=…]` checks. `Decimal("19.99")` evades the whitelist. Test missing, zero and varied prices and retain a targeted guard against price defaults.
- Delete the licence length and generic HTML-tag checks. GNU’s text contains `<year>`. Verify the reviewed canonical bytes, the wheel’s licence file and its `AGPL-3.0-or-later` metadata. [GNU licence text](https://www.gnu.org/licenses/agpl-3.0.html)

## Answers to the three open questions

**(a) `--rules DIR`** — Defer it to the installed distribution in Phase 4. Phase 1 users can edit YAML in a clone. Prove that changing a rule changes the report through the documented CLI command.

**(b) English-only help** — English is a reasonable default. English-only, hardcoded project help conflicts with `AGENTS.md`. Put project-owned help in both locales and test German help and invalid-option messages through the CLI.

**(c) Skipped collector** — Yes. D-18 requires Unknown for an explicitly skipped collector. Show provided counts, their source and any known risk alongside that status. A manual-only workload with no collector expected can use complete provided evidence.
