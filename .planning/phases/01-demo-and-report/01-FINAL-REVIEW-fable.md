# Final review and security audit: Befund phase 1 (reviewer: Claude Fable 5.2)

Reviewed at HEAD `e8975a3` on 2026-11-21. Not read: `drafts/`, `grants/`, the other reviewer's file.

## Verdict

**Release after fixes.** The tool itself is sound: parsing, output writing, the offline report and the cost arithmetic all held up under attack, and 466 tests pass. What would embarrass the project is around the tool: a placeholder sample report on the site, a placeholder footer in every report, a security policy written for a private repository, an install command for a package name nobody has reserved, and a licence classifier that only works on the curated samples.

## What I ran

`uv run --locked befund demo` (de, en, nonprofit), `pytest -q` (466 passed, 113 s), `ruff check`, `site/check_site.py`, and about 50 hand-made scan and inputs files through `befund report`. Town totals recomputed by hand from `demo/town/inputs.yaml`: stay 600,000; partial 422,800 + 46,000 + 9,000 + 50,000 = 527,800 (−72,200); full 213,350 + 126,000 + 25,000 + 100,000 = 464,350 (−135,650). All match the report. The three action SHAs in `ci.yml` match their upstream tags (`git ls-remote`), and the five openDesk documentation URLs cited in the report return 200.

Each gave one sentence with the file base name and the field, exit code 2, no traceback and no partial output.

## What to delete

- `rules.rule_file_checksums` (`rules.py:147-161`): only a test calls it; the report computes checksums another way.
- The `code` value type: `"code"` in `catalogue.VALUE_TYPES`, both `_VALUE_CODE` patterns, and the string branches in `model.finding_value` and `rules._literal_matches`. No catalogue entry uses it.
- `model.SCHEMA_VERSION` (never read), `inputs.empty_inputs()` (it is `Inputs()`), and the `provided` parameter of `render_report` (tests only).
- About 47 of the 145 rows in `service_plans.yaml` cover US government, DoD, education and Telstra products. They are outside the stated market, while the EEA "no Teams" suites that this market has bought since 2023 are, as far as I can see, absent.
- `img-src data:` in the report's CSP: the report has no images.
- `HANDOFF.md`, `.claude/CLAUDE.md` and `.planning/` from the public tree, once the principles have a current home (M6).
- `render_report` is about 110 lines, against "functions that fit on a screen". Split the data preparation from the template call.

## What is good and must not be lost

- The loader design: registered codes only, unknown fields counted but never echoed, keys reported by position, and errors that name only the file's base name.
- `write_inside`: resolved directory, refusal of links, same-directory temporary file, atomic replace, mode 0600, cleanup on failure.
- The offline guarantee is real: no script, link, image or `href` in the output, CSP `default-src 'none'`, autoescape on, and `test_report_cannot_fetch_resources` parses the HTML rather than searching for strings.
- The socket audit hook in `conftest.py` and in the installed-wheel subprocess, the SHA-pinned actions, `uv sync --locked` and the fixed `exclude-newer`.
- The evidence model: unknown stays unknown with a reason and a next step, a skipped collector cannot produce Ready, and the cost arithmetic in exact twelfths reproduces by hand.
