## What to delete

- Replace the empty `REPOSITORY_URL` and “Repository address pending” footer with the public address already on the site.
- Remove the unused `code` finding type and its unconstrained string-value branch. All 40 current findings are counts, bytes or booleans.
- Drop the repeated null reference and check-date fields from the generic mapping. Its loader already accepts their omission.
- Remove repeated three-item evidence lists for every function in the same workload ([src/befund/templates/report.html.j2:734](../../../src/befund/templates/report.html.j2#L734)). Reference the existing workload evidence once and retain the deciding reason.

## What is good and must not be lost

- The town's five-year amounts reconcile in both languages. Staying is 5 × (€100,000 + €20,000) = **€600,000**. Partial exit is €422,800 running + €46,000 project + €9,000 productivity + €50,000 parallel = **€527,800**. Full exit is €213,350 + €126,000 + €25,000 + €100,000 = **€464,350**. Partial running includes €60,000 × 54/12 in retained licences and €8.50 × 30 × 60 in hosting. Full-exit training is 2 × €400 × 85 = €68,000. Differences from staying are −€72,200 and −€135,650.
- Both HTML files opened at 360 px in offline Firefox with no horizontal overflow or external resource requests. The A4 PDFs retained the cost totals and evidence. Preserve autoescaping, the restrictive CSP and text status labels.
- Duplicate JSON and YAML keys, non-finite numbers and a Boolean in a count field all produced a one-line error and exit 2. The installed-wheel socket audit also records attempts caught by the application.
- CI has read-only repository permissions, disables persisted checkout credentials and pins all three actions by commit. The report records checksums for the rules actually used.
