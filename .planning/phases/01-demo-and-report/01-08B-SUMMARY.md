# Plan 01-08B summary

Befund now protects identifiers in reports and scan copies, bounds file reads, and checks all demo destinations before writing. The report records the scan's origin and producer separately from the rendering version. The public site serves the two generated town reports and checks both against fresh CLI output in CI.

## Public interfaces

- `befund` exports `PROJECT_NAME = "befund"`, `REPOSITORY_URL = "https://github.com/rouxdutoit/befund"` and `__version__`. The entry point is `befund.cli:main() -> None`. The Typer application is `befund.cli.app`.
- `befund [--debug] demo [--lang en|de] [--sample town|nonprofit] [--profile opendesk|nextcloud|generic] [--out DIR]` defaults to `en`, `town`, `opendesk` and `./report`. `befund [--debug] report SCAN_JSON [--inputs FILE] [--lang en|de] [--profile opendesk|nextcloud|generic] [--out DIR]` resolves language and profile from flags, inputs, then defaults. Both support `--help`. Global `--version` prints the installed version. The final stdout line is the absolute report path. Demo also writes `scan-<YYYY-MM-DD>-<lang>.json` and `inputs-<YYYY-MM-DD>-<lang>.yaml`. Paths with nonprintable characters display those characters as escapes. Input errors exit 2 with one localized sentence unless `--debug` is set. Help and Typer usage errors are English.
- `errors.InputError(code: str, *, file: str | None = None, field: str | None = None, **details: object)` exposes `code`, `file`, `field` and `details`. `i18n.escape_controls(text: str) -> str` formats paths for display. `i18n.error_sentence(strings: dict, error: InputError) -> str` formats diagnostics.
- `parsing.MAX_FILE_BYTES = 2_097_152`. `parsing.read_text(path: Path | Traversable) -> str`, `parse_json(text: str, file_name: str) -> object`, `parse_yaml(text: str, file_name: str, *, quoted_fields: tuple[str, ...] = (), allow_aliases: bool = True) -> object` and `reject_at_signs(value: object, file_name: str, field: str = "$") -> None` support validation. The inputs reader passes `allow_aliases=False`.
- `catalogue.load_catalogue(path: Path | None = None) -> Catalogue` returns a frozen catalogue with `workloads`, `findings`, `collector_ids`, `source_codes`, `reason_codes`, `permissions`, `provided_sources`, `sku_exceptions`, `file_name` and `checksum`. It exposes `workload_ids: tuple[str, ...]`, `finding(finding_id: str) -> FindingEntry | None` and `accepts_sku_part_number(part_number: object, guid: str) -> bool`. The frozen entries are `WorkloadEntry(id, label)` and `FindingEntry(id, workload, type, unit, label, provided, headline, measured_by)`. The value types are `count`, `bytes` and `boolean`.
- `model.load_scan(path: Path, catalogue: Catalogue) -> Scan`, `load_scan_text(text: str, file_name: str, catalogue: Catalogue) -> Scan` and `scan_to_json(scan: Scan, *, plans: tuple[rules.ServicePlan, ...]) -> str` are the scan I/O. Pass the trusted classification records from `rules.load_service_plans` to the serializer. `FindingValue = int | bool`. `Scan(schema_version, tool, generated_at, source_kind, collectors, findings, licences, dropped_count=0)` exposes `finding(finding_id: str) -> Finding | None` and `collector(collector_id: str) -> Collector | None`. Scan JSON omits `dropped_count`.
- The frozen evidence records are `model.ToolInfo(name, version)`, `Collector(id, status, reason, permissions_used)`, `Coverage(kind, scanned=None, failed=None, total=None)`, `Finding(id, workload, value, unit, provenance, collector, source, collected_at, period, coverage, missing_reason)` and `Licences(collector, source, collected_at, coverage, products)`. A frozen `Product(sku_part_number: str | None, sku_guid: str | None, purchased: int, assigned: int, service_plans: tuple[model.ServicePlan, ...])` exposes `key: tuple[str, str] | None`. An anonymous SKU uses two null identifiers. A frozen `model.ServicePlan(name: str | None, guid: str | None)` can have one or both identifiers null in the copy. The copy retains counts and registered components needed to classify the evidence after a rebuild.
- `rules.load_service_plans(catalogue: Catalogue, path: Path | None = None, *, checksums: MutableMapping[str, str] | None = None) -> tuple[ServicePlan, ...]` returns frozen classification records with `sku_part_number`, `sku_guid`, `name`, `guid`, `workload`, `signal`, `reference_url`, `checked_on` and `note`. `classify_product(product: model.Product, plans: tuple[ServicePlan, ...]) -> tuple[ServicePlan | None, ...]` returns matches in observed order. `licence_findings(scan: Scan, plans: tuple[ServicePlan, ...], catalogue: Catalogue) -> tuple[Finding, ...]` derives the product count and workload signals. The other rule loaders still accept the optional `checksums` mapping.
- `inputs.load_inputs(path: Path, catalogue: Catalogue) -> Inputs`, `load_inputs_text(text: str, file_name: str, catalogue: Catalogue) -> Inputs`, `provided_findings(inputs: Inputs, catalogue: Catalogue) -> tuple[Finding, ...]` and `combine(scan: Scan, provided: tuple[Finding, ...]) -> tuple[Scan, tuple[Finding, ...]]` handle interview evidence. Frozen `Inputs` holds `organisation_name`, `currency`, `language`, `target_profile`, `as_of`, `amounts_are_invented`, `current_costs`, `partial_exit`, `full_exit`, `windows_only_software`, `provided_counts`, `confirmations` and `answers_are_sample`. Use `Inputs()` for empty answers. Its frozen component records are `CurrentCosts(microsoft_licences_per_year, other_it_per_year)`, `ScenarioInputs(users, retained_microsoft_licences_per_year, hosting_per_user_per_month, operations_per_year, other_recurring_per_year, one_time_migration, application_adaptation, external_advice, training_days_per_person, training_day_rate, training_staff, productivity_loss, parallel_running_months)` and `WindowsSoftware(name, users=None, vendor_has_web_version=None)`.
- `output.write_inside(out_dir: Path, file_name: str, text: str) -> Path` and `write_files(out_dir: Path, outputs: Mapping[str, str]) -> tuple[Path, ...]` return resolved destinations. The latter returns them in mapping order, preflights the group and stages all content before atomic per-file replacement.
- `report.render_report(scan: Scan, *, lang: str, profile: str = "opendesk", catalogue: Catalogue | None = None, inputs: Inputs | None = None) -> str` renders HTML. `render_demo(scan: Scan, *, lang: str, profile: str, catalogue: Catalogue, inputs: Inputs) -> tuple[str, str]` returns HTML and the privacy-safe JSON copy using the same service plan data. `report_file_name(generated_at: str, *, lang: str) -> str` returns `report-<YYYY-MM-DD>-<lang>.html`. The nine `SECTION_ORDER` IDs remain the report contract. Mapping rows link to their workload's `#readiness-<workload>` evidence. The run details expose `data-source-kind`, `data-scan-producer`, `data-producer-version` and `data-renderer-version`.

## Deviations and open items

- The restriction on editing `HANDOFF.md` took precedence over the historical note requested in item 14.
- The header identifies the logical file `scan.json` because a user's actual filename can contain private information. Anonymous licence identifiers use JSON nulls to preserve counts and allow rebuilds without inventing replacement IDs.
- Typer 0.28.0 wraps the uppercase `SCAN_JSON` metavar in braces. The literal lowercase placeholder `{scan_json}` is absent.
- The D-71 rejection of directory-handle pinning stands. Invalid destinations and staging failures leave existing outputs intact. A failure during the final replacements can occur after an earlier file has been replaced.
- The founder's confirmation of the initial-history attestation is pending. The founder owns the D25 trademark decision. Hosted GitHub settings and publication are orchestrator work.
