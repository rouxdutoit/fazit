## Phase Goal

Anyone can run `demo` and `report` and get an honest, self-contained report in German or English, with per-workload status, evidence on every finding and three cost scenarios, without a Microsoft account, without network access and before any Microsoft code exists.

> This is the ROADMAP.md goal line, copied as written. It is not in user-story form. No story was invented for it. `/gsd-mvp-phase 1` sets one.

<objective>
Build the walking skeleton and the evidence model: one command writes one real report from bundled sample data, in German or English, and the public shape of `scan.json` is fixed and enforced by an allowlist loader.

Purpose: Every later plan and every later phase builds on what this plan fixes: the package layout, the catalogue of workloads and finding ids, the `scan.json` model with its licences block and coverage object, strict parsing, the error style and the locale mechanism.
Output: An installable package with the command `demo`, the catalogue, two sample scans that cover all fifteen workloads, both locale files, and tests that run with every socket call blocked.

This is plan 1 of 7. The plans run one at a time, in order (D-39); wave numbers only express that order. They are run by Codex, name plain file paths, and each summary records the public signatures the next plan needs (D-57).

</objective>
