## Phase Goal

Anyone can run `demo` and `report` and get an honest, self-contained report in German or English, with per-workload status, evidence on every finding and three cost scenarios, without a Microsoft account, without network access and before any Microsoft code exists.

> This is the ROADMAP.md goal line, copied as written. It is not in user-story form. No story was invented for it. `/gsd-mvp-phase 1` sets one.

<objective>
Let the user supply what no scan can see: `inputs.yaml` with answers, counts and costs, carried into the report as provided evidence, together with the example file and the interview checklist that fill it.

Purpose: Most workloads need a confirmation only a person can give. This plan closes that gap, so the demo shows all four statuses on real evidence, and it gives the assessor the checklist that asks for exactly those confirmations.
Output: `inputs.py`, two sample `inputs.yaml` files, `--inputs` on `report`, `inputs.example.yaml`, and the checklist in English and German.

This is plan 5 of 7 (D-39). The cost keys are read and validated here; the cost arithmetic and its section are plan 01-06.
</objective>
