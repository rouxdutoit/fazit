## Phase Goal

Anyone can run `demo` and `report` and get an honest, self-contained report in German or English, with per-workload status, evidence on every finding and three cost scenarios, without a Microsoft account, without network access and before any Microsoft code exists.

> This is the ROADMAP.md goal line, copied as written. It is not in user-story form. No story was invented for it. `/gsd-mvp-phase 1` sets one.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| scan file → report and printed output | Anything in a scan file from elsewhere could be personal or secret. |
| `--out` → file system | The path given on the command line decides where files are written. |
| report file → browser | The file is opened by people who did not run the tool. |
