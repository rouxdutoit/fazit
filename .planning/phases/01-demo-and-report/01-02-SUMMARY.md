# Plan 01-02 summary

`report` rebuilds a local HTML report from a validated scan. `demo` writes one HTML report, a scan copy serialized from the validated model, and a bundled inputs copy. Every output goes through the same atomic writer. The HTML has a restrictive content security policy, localized table labels, light and dark colours, a stacked layout at phone width, and print styles that preserve row boundaries and provenance labels.

## Public interfaces

- `output.write_inside(out_dir: Path, file_name: str, text: str) -> Path` returns the absolute destination inside the resolved directory. It writes UTF-8 to a temporary file in that directory and replaces the target atomically. Output errors use `out_dir`, `destination_is_link` and `write_failed` with `--out` as the field.
- `model.load_scan(path: Path, catalogue: Catalogue) -> Scan` and `model.load_scan_text(text: str, file_name: str, catalogue: Catalogue) -> Scan` validate schema 1.x. `model.scan_to_json(scan: Scan) -> str` serializes the model with sorted keys and a final newline. The internal `dropped_count` is excluded from the JSON.
- `model.Scan(schema_version: str, tool: ToolInfo, generated_at: str, source_kind: str, collectors: tuple[Collector, ...], findings: tuple[Finding, ...], licences: Licences | None, dropped_count: int = 0)` provides `finding(finding_id: str) -> Finding | None` and `collector(collector_id: str) -> Collector | None`.
- `model.ToolInfo(name: str, version: str)`, `model.Collector(id: str, status: str, reason: str | None, permissions_used: tuple[str, ...])` and `model.Coverage(kind: str, scanned: int | None = None, failed: int | None = None, total: int | None = None)` are frozen, as are the other model dataclasses.
- `model.Finding(id: str, workload: str, value: FindingValue | None, unit: str | None, provenance: str, collector: str | None, source: str | None, collected_at: str | None, period: str | None, coverage: Coverage | None, missing_reason: str | None)` uses `FindingValue = int | bool | str`.
- `model.Licences(collector: str, source: str, collected_at: str, coverage: Coverage, products: tuple[Product, ...])` holds `model.Product(sku_part_number: str, sku_guid: str, purchased: int, assigned: int, service_plans: tuple[ServicePlan, ...])` and `model.ServicePlan(name: str, guid: str)`.
- `parsing.reject_at_signs(value: object, file_name: str, field: str = "$") -> None` checks parsed keys and values and raises `InputError("contains_at", ...)` with a structural path.
- `report.render_report(scan: Scan, *, lang: str, catalogue: Catalogue | None = None) -> str` and `report.report_file_name(generated_at: str, *, lang: str) -> str` produce HTML and `report-<YYYY-MM-DD>-<lang>.html`. `report.SECTION_ORDER` lists `header`, `found`, `costs`, `readiness`, `moves`, `attention`, `path`, `appendix` and `footer`. The template currently renders `header`, `found`, `appendix` and `footer`. CSS defines `--bg`, `--text`, `--muted`, `--line`, `--accent` and `--surface`.
- `cli.app` is the Typer application. `cli.main() -> None` is the console entry point. `m365-exit-scan [--debug] report SCAN_JSON [--lang en|de] [--out DIR]` defaults to `en` and `./report`. `m365-exit-scan [--debug] demo [--lang en|de] [--sample town|nonprofit] [--out DIR]` defaults to the same language and output directory and the `town` sample. Its copies are named `scan-<YYYY-MM-DD>-<lang>.json` and `inputs-<YYYY-MM-DD>-<lang>.yaml`. Both commands print the absolute HTML path on the last line. Global `--version` prints the package version. Input errors exit 2 with one localized sentence on stderr, and global `--debug` exposes the exception.
