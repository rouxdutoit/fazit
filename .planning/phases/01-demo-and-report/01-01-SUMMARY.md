# Plan 01-01 summary

The installable `m365-exit-scan` package provides `demo` for the town and nonprofit samples in English and German. Each sample covers 39 findings across 15 workloads. The loader validates evidence, licence identifiers and coverage against the versioned schema and the packaged catalogue. The self-contained HTML report shows headline figures, evidence and provenance, reasons and fixes for missing findings, and collector details. The only output is one atomically written report inside `--out`.

## Public interfaces

- `m365_exit_scan` exports `PROJECT_NAME`, `REPOSITORY_URL` and `__version__`. The repository URL is currently empty.
- `errors.InputError(code: str, *, file: str | None = None, field: str | None = None, **details: object)` exposes `code`, `file`, `field` and `details`.
- `parsing` exports `read_text(path: Path | Traversable) -> str`, `parse_json(text: str, file_name: str) -> object` and `parse_yaml(text: str, file_name: str) -> object`. File reads preserve UTF-8 text and line endings.
- `catalogue` exports `VALUE_TYPES` and `load_catalogue(path: Path | None = None) -> Catalogue`. The default is packaged `rules/findings.yaml`.
- `catalogue.WorkloadEntry(id: str, label: str)` and `catalogue.FindingEntry(id: str, workload: str, type: str, unit: str | None, label: str, provided: str, headline: bool)` are frozen.
- `catalogue.Catalogue(workloads: tuple[WorkloadEntry, ...], findings: tuple[FindingEntry, ...], collector_ids: frozenset[str], source_codes: frozenset[str], reason_codes: frozenset[str], permissions: frozenset[str])` is frozen. It exposes `workload_ids: tuple[str, ...]` and `finding(finding_id: str) -> FindingEntry | None`.
- `model` exports `SCHEMA_VERSION = "1.0"`, `SUPPORTED_SCHEMA_MAJOR = 1`, `SOURCE_KINDS`, `COLLECTOR_STATUSES`, `PROVENANCES`, `COVERAGE_KINDS` and `FindingValue = int | bool | str`.
- `model.ToolInfo(name: str, version: str)` and `model.Collector(id: str, status: str, reason: str | None, permissions_used: tuple[str, ...])` are frozen.
- `model.Coverage(kind: str, scanned: int | None = None, failed: int | None = None, total: int | None = None)` is frozen.
- `model.Finding(id: str, workload: str, value: FindingValue | None, unit: str | None, provenance: str, collector: str | None, source: str | None, collected_at: str | None, period: str | None, coverage: Coverage | None, missing_reason: str | None)` is frozen.
- `model.ServicePlan(name: str, guid: str)`, `model.Product(sku_part_number: str, sku_guid: str, purchased: int, assigned: int, service_plans: tuple[ServicePlan, ...])` and `model.Licences(collector: str, source: str, collected_at: str, coverage: Coverage, products: tuple[Product, ...])` are frozen. GUIDs are normalised to lower case.
- `model.Scan(schema_version: str, tool: ToolInfo, generated_at: str, source_kind: str, collectors: tuple[Collector, ...], findings: tuple[Finding, ...], licences: Licences | None, dropped_count: int = 0)` is frozen. It exposes `finding(finding_id: str) -> Finding | None` and `collector(collector_id: str) -> Collector | None`.
- `model.load_scan_text(text: str, file_name: str, catalogue: Catalogue) -> Scan` and `model.load_scan(path: Path, catalogue: Catalogue) -> Scan` construct the model from known fields and finding IDs.
- `i18n` exports `SUPPORTED_LANGUAGES = ("en", "de")`, `DEFAULT_LANGUAGE = "en"`, `load_locale(lang: str) -> dict`, `error_sentence(strings: dict, error: InputError) -> str`, `code_label(strings: dict, group: str, code: str) -> str` and `reason_text(strings: dict, code: str) -> tuple[str, str]`.
- `i18n.Formatter(lang: str)` exposes `strings: dict` and provides `integer(value: int) -> str`, `storage(value: int) -> str`, `date(value: str) -> str` and `period(value: str) -> str`. Storage uses decimal units and rounds half up to one decimal place.
- `output.write_inside(out_dir: Path, file_name: str, text: str) -> Path` returns the resolved output path. Output errors use `out_dir`, `destination_is_link` and `write_failed`.
- `report.report_file_name(generated_at: str, *, lang: str) -> str` returns `report-<YYYY-MM-DD>-<lang>.html`. `report.render_report(scan: Scan, *, lang: str, catalogue: Catalogue | None = None) -> str` returns HTML. `SECTION_ORDER` lists all nine planned IDs. The current template renders `header`, `found`, `appendix` and `footer`.
- `cli.app` is the Typer application and `cli.main() -> None` is the console entry point. Run `m365-exit-scan [--debug] demo [--lang en|de] [--sample town|nonprofit] [--out DIR]`. Defaults are `en`, `town` and `./report`. Global `--version` prints the package version. Input errors exit 2 with one sentence on stderr. Global `--debug` exposes the exception.
